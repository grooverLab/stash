5 · Audit findings

All resolved 2026-07-23 - kept for history.

#SeverityFindingResolutionStatus
1HIGH python3 remnant. use and off recorded state via python3 heredocs while the pickers were shell-only. Both heredocs replaced by the shared write_state() printf writer. Zero python anywhere. FIXED
2HIGH State schema divergence. use/off wrote {active} only and merged names; pickers rebuilt {active, partial} - an off after a picker run silently dropped partial data. One writer everywhere: write_state() recomputes {active, partial} FROM THE LINKS on disk. Links are the truth; json is a cache. Verified by round-trip test incl. manual link removal. FIXED
3MED Guard asymmetry. pick-html only checked PWD=HOME; TUI also checked the resolved path. pick-html now carries the same two-condition guard as the TUI. FIXED
4MED Stale self-documentation. Header said "pick = HTML picker"; usage omitted pick-html. Header rewritten (pick = TUI, pick-html = browser); usage line lists both. FIXED
5LOW Unanchored profile count in pick-html's state writer (grep -cF "prof/"). Block deleted entirely - superseded by write_state(), which counts links with [ -e ] checks, no grep. FIXED
6LOW Hardcoded migrate routing. profile_for() encodes the author's vendor paths. Kept by design; README documents editing profile_for() for your own layout. BY DESIGN
7HIGH Unbound-variable crash. set -u + bare $SP_NO_OPEN / $CLAUDECODE: pick-html died in a default environment before opening the browser, or after applying but before launching claude. ${VAR:-} expansion at both sites. Reproduced, then verified end-to-end with a real form POST. FIXED
8HIGH Empty profile corrupted the project dir. An empty profile directory left the literal glob unexpanded - use created a symlink named * in .claude/skills/. shopt -s nullglob; empty profiles now link 0 skills. Reproduced before, clean after. FIXED
9MED Diff engine triplicated. The same add/remove logic lived in use/off, the TUI's apply(), and pick-html's inline loop - three places to drift. One apply_selection() + hidden _apply subcommand; the TUI pipes its selection, pick-html calls the function. TUI shrank ~25 lines. FIXED
10MED update aborted on first failure. pipefail made one diverged vendor repo kill the whole pull loop. || true on the capture; the failure line still prints per repo. FIXED
11MED status served a stale cache, contradicting "the links are the truth". status now recomputes via write_state before printing. FIXED
12MED use/off/status unguarded from $HOME - running them there silently edited the GLOBAL skills dir, despite the README's guard-rails claim. Shared require_project() now guards every project-level command; pickers included. FIXED
